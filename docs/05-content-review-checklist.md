# Content review checklist

The guides were written from published manufacturer manuals, EPA and OSHA documents and trade articles, not from the IICRC standards themselves. Each needs one read by someone with field experience. Mark anything wrong and it is a quick fix.

For each page: is it true on a real job, is anything missing that causes problems, and would you hand it to a new tech?
