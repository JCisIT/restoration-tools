# Compliance and value assessment

Build tools that document scope, quantities and conditions. Do not build tools for contractors that interpret insurance policies or negotiate claims. That one line separates the safe, valuable tools from the ones that create legal exposure.

This is a working assessment from published sources, not legal advice. Have an insurance attorney review it before charging money for anything or collecting leads.

## The line that matters

Contractors can document what the work is and what it costs. In many states they cannot interpret the policy or negotiate the claim for the owner without a public adjuster licence.

- **Florida:** the contractor statute (section 489.147) bars contractors from interpreting policy provisions or advising an insured on coverage unless licensed as public adjusters.
- **Texas:** Insurance Code section 4102.163 bars contractors from acting as adjusters, or advertising that they adjust claims, on jobs they are working. The Texas Supreme Court upheld it in 2024 and treated negotiating loss amounts as adjusting.

## Other rules the site is built around

- **Xactimate:** only read PDFs the user uploads. Do not store line prices or automate Xactimate itself. Verisk's licence restricts both.
- **IICRC standards:** use the published formulas, name the standards, never copy their text or imply endorsement.
- **Florida assignment of benefits:** eliminated for property policies from 2023. No such templates.
- **Homeowner data:** estimates carry names, addresses and claim numbers. The site stores no documents.
- **Marketing wording:** never "get more from the carrier" or "we fight the insurance company".

## PDF to ESX conversion

Reading a PDF estimate is easy. Writing a file Xactimate will import is the hard part, because the ESX format is proprietary and undocumented, and Verisk now sells this conversion itself. The site links to Verisk's tool instead of rebuilding it.
