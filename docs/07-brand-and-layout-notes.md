# Brand and layout notes

The site uses a sidebar layout in the 9 Construction brand. It was chosen from five options because the sidebar scales as tools are added and the brand ties the site to the company.

## Layout options that were considered

The original mockups are on the design canvas: https://claude.ai/artifact/D5RTV224wgtSBofPHWauXu

| Option | Layout | Colour scheme | Outcome |
| --- | --- | --- | --- |
| A | Full-width bands | 9 Construction | Colours kept |
| B | Card grid | Blueprint blue | Not used |
| C | Tool-first homepage | Warm grey and rust | Idea reused on tool pages |
| D | Sidebar directory | Dark teal | Layout kept |
| E | Sidebar with the tool on the page | Switchable | Chosen, in 9 Construction colours |

The homepage later changed from "the calculator is the homepage" to a proper landing page with a stencil headline, a "who it's for" section and a tools grid.

## Colours

| Name | Hex | Used for |
| --- | --- | --- |
| Charcoal | #0E0E0E | Sidebar, hero, text |
| Olive | #5A6B46 | Rules, section bars, labels |
| Forest | #2E3A28 | Result panels, table headers |
| Bone | #E6E1D6 | Light panels, text on dark |
| Orange | #D88A1A | The single accent: one button per view |
| Muted ink | #4A4F44 | Secondary text on white |

Orange text is never placed on white or bone, and white text is never placed on orange. Both fail contrast.

## Type

- **Headings:** Oswald SemiBold, uppercase
- **Body:** Inter
- **Homepage headline and large numerals:** Big Shoulders Stencil

## Layout rules

- Square corners everywhere except buttons and inputs.
- The sidebar groups tools as Drying, Mold and air, and Job math, then Guides.
- On phones the sidebar becomes a Menu button and closes after a tap.
- Every tool ends with "Next steps" links to the tools and guides that follow it.
- Result panels are forest green with bone text, on the right on desktop and below on phones.
- Guides and forms have a print layout with the sidebar removed.
